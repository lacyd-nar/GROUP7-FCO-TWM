# Peer Reviewed Application of Laplace Transform for Solving Improper Integrals whose Integrand Consisting Error Function

Final Course Output (Mini Research and Exposition Paper) TWM 301: Technical Writing (for BS Mathematics) | Bulacan State University, College of Science | A.Y. 2026-2027, First Semester

This repository contains the LaTeX source of the group's final course output. The paper is an exposition and critical peer review of Aggarwal, Singh, Kumar, and Kumar (2019), who evaluate improper integrals containing the error function by Laplace transform. The paper re-derives the key transform, works through the article's six integrals, checks each numerically, and documents the errors found in the article.

## Summary of the Paper

Key result: the Laplace transform of erf(sqrt(t)) is 1 / (s * sqrt(s + 1)) for all s > 0, derived by an integral-representation argument (all s > 0) and by the term-by-term series of the source article (valid for s > 1 only).

Applications: six improper integrals evaluated with the definition, multiplication by t, first shifting, the integral property, change of scale with the derivative property, and the convolution theorem.

Verification: each exact value is compared with independent adaptive numerical quadrature (agreement to at least six significant digits). The truncation error of the series is analysed with the alternating-series bound.

Peer review: a table of errors and omissions in the source article (wrong limit of erfc, incorrect transform of t*erf(sqrt(t)) in Eq. (11), misstated change-of-scale property, missing convergence conditions, inconsistent issue number, a spelling error).
