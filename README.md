# Application of Laplace Transform for Solving Improper Integrals Involving the Error Function

## Project Overview

This repository contains the group's Final Course Output for TWM 301: Technical Writing for BS Mathematics at Bulacan State University.

The paper presents an exposition and critical review of the 2019 article by Aggarwal et al. on using the Laplace Transform to evaluate improper integrals involving the error function.

The study focuses on deriving the Laplace Transform of the error function, applying its properties to evaluate six improper integrals, and verifying the results through numerical computation.

## Main Topics

1. Definition and properties of the Laplace Transform.
2. Definition and properties of the error function.
3. Derivation of the Laplace Transform of the error function.
4. Evaluation of six improper integrals.
5. Numerical verification of the computed results.
6. Critical review of the original research article.

## How to Compile the Paper

1. Clone or download this repository.
2. Open `TWM project.tex` using a LaTeX editor.
3. Make sure the two image files are in the same directory as the LaTeX source.
4. Compile the document using PDFLaTeX.
5. Compile again if necessary to update the table of contents, figures, and references.

## Numerical Verification

The paper compares the analytical results of six improper integrals with numerical approximations obtained through adaptive numerical quadrature.

The numerical results are used to verify the accuracy of the derived exact values.

The Python implementation and separately generated numerical output files will be included in the repository.
